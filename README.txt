ESTATE XPERTS WEBSITE

This is a separate static public website. It does not modify your Kerala Property App or its database.

FILES
- index.html: website page
- properties.json: public property listing data
- assets/style.css: design
- assets/app.js: search, filters and WhatsApp enquiry

TO PREVIEW
Open index.html in a browser. For reliable local preview, use a simple local web server because the page fetches properties.json.

TO PUBLISH
Upload the complete estate_xperts_website folder to a static hosting provider. Keep index.html, properties.json and the assets folder together.

PRIVACY
The exported JSON includes public listing fields only. It does not include owner names, owner phone numbers, exact map coordinates, nearby landmark text, ceiling or beam details.
